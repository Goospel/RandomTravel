## 🍃 오버투어리즘 대응 (지정과제 2번)

| 기능 | 하는 일 |
|---|---|
| 🍃 **한적 필터 + 오늘의 한적 TOP5** | 관광지 집중률 **예측** 데이터로 "덜 붐빌 것으로 예측되는 곳"만 뽑는다. 홈에 오늘의 하위 5개 시·군·구를 칩으로 노출하고, 탭하면 그 동네에서 바로 뽑는다 (예측이 낡으면 아예 띄우지 않는다) |
| 🔭 **빈 곳에서 뽑기** | **내가 안 가본 ∩ 한적한** 시·군·구 교집합에서만 뽑는다 — 유명지 반복 방문을 구조적으로 비껴간다 |
| ⚖️ **분산 모드** | 지역을 안 고르면 17개 시·도 **진짜 균등**(법정동 버킷)으로 뽑고, 방문자가 적은 시·도에 √역가중을 더 줄 수 있다 |
| 📈 **임팩트 대시보드** [`/impact`](https://travelanywhere-kr.vercel.app/impact) | ① 공공 데이터 기준 **시·도 방문 편중 실측**(서울↔세종 71.1배) ② 우리 뽑기의 **설계 확률**(해석적 계산) ③ 익명 수집 기반 **실제 제안 분포·반응 퍼널**. 표본 수를 상시 노출하고 "설계 확률 — 실측 아님"을 화면에 못박는다 |

> 검색은 사용자가 이미 아는 곳만 강화한다. 랜덤은 **모르는 곳을 후보에 올리는** 유일한 방식이고, 여기에 조건(날씨·한적·시점·대상)을 얹은 것이 이 서비스다.

## ✨ 핵심 기능

**뽑기**

- 🎰 **순수 랜덤** — 버튼 하나로 전국 어디든. 홈의 250조각 시·군·구 지도가 룰렛처럼 점멸하다 당첨 동네에 착지한다
- 🎯 **조건 랜덤** — 지역·테마를 고른 뒤 그 안에서 랜덤. **조건을 하나도 안 걸면 완전 랜덤**
- ☔🎪🌊🦀🍃 **조건 필터** — "지금 비 안 오는 곳" · "축제 진행 중" · "바다 보이는 곳" · "제철 재료 산지" · "한적한 곳"
- 📅 **방문 시점 칩** — 오늘/내일/이번·다음 주말 기준으로 🍃🎪🦀 판정 날짜를 바꾼다 (☔는 오늘 전용)
- 📍 **주변에서 뽑기** — 뽑힌 곳을 거점 삼아 반경 20km 안에서 다시 추천
- 🐕♿ **대상 한정** — 반려동물과 함께 갈 수 있는 곳 / 휠체어·보조견 등 무장애 정보가 있는 곳
- 🚫 도서관·수련시설 같은 생활 시설은 여행지에서 자동 제외

**여행 준비·기록**

- 🃏 **결과 카드** — 사진·주소·설명 + 카카오맵 길찾기 + "다시 뽑기"
- 🧭 **반나절 코스** — 뽑힌 곳을 앵커로 볼거리 → 식사 → 카페 3스텝 타임라인 (스텝 재뽑기·전체 재생성)
- 💬 **카톡 공유** — 사진·제목·지도 링크가 담긴 카드로 (Web Share·링크 복사 폴백)
- ❤️ **찜 / 최근 본 곳 / 다녀옴** — 로그인 없이 `localStorage`에 저장
- 🧩 **전국 정복 지도** [`/map`](https://travelanywhere-kr.vercel.app/map) — 다녀온 곳이 250개 시·군·구를 채우고 정복률·탐험가 레벨로 쌓인다
- 📊 **재방문 의향 평가** — 👎 또 안 감 · 😐 그럭저럭 · 👍 또 갈래
- 🔐 **로그인·동기화(선택)** — 구글·카카오 로그인 시 여러 기기에서 동기화. 안 해도 그대로 사용
- 📲 **PWA** — 폰 홈 화면에 설치 (iOS는 공유→홈 화면 안내)

## 🏗️ 데이터 아키텍처 — 실시간 vs 일 1회 배치

- **관광 콘텐츠는 전량 실시간 호출**한다 — 저장하지 않고 요청 때마다 상류에서 받아 그대로 카드로 만든다.
- **집중률·방문자수 2종만 일 1회 배치**로 받아 Postgres에 적재한다 (`/api/cron/congestion`, Vercel Cron **KST 08시** — 데이터가 매일 07:30 이후 갱신되므로 그 뒤). 이유는 실시간이 불가능해서다: "전국에서 가장 안 붐비는 곳"은 **252개 시·군·구를 서로 비교해야 나오는 백분위**라 요청 1건당 252콜이 필요하고, 원본이 일 단위 갱신이라 실시간으로 얻을 이득이 0이다.
- 그래서 **사용자 요청 경로에서 이 2종의 외부 호출은 0콜**이고, DB 조회만 한다. 로컬 저장은 한국관광공사에 신청서를 제출했다(2026-07-29, 승인 대기).

## 🛠️ 기술 스택

| 영역 | 사용 |
|---|---|
| 프레임워크 | Next.js 16 (App Router) + React 19 + TypeScript strict |
| 스타일 | Tailwind CSS v4 (CSS 변수 토큰 · 다크 모드 변수 스왑) |
| 데이터 | 공공데이터 OpenAPI (위 표) — 전부 서버 프록시 경유 |
| 지도 | 카카오맵 (링크 + JS SDK 임베드) · 정복 지도는 순수 SVG |
| 인증 | Auth.js v5 (구글·카카오 OAuth · JWT 세션) — 선택적 로그인 |
| 저장 | localStorage(비로그인 폴백) + Neon Postgres(로그인 시 동기화) · Drizzle ORM |
| 테스트 | Vitest (순수 함수 단위 테스트, TDD) |
| 배포 | Vercel (함수 리전 서울 `icn1` · Cron) |

## 🚀 시작하기

```bash
npm install

# 환경변수 준비 — 예시 파일을 복사해 서비스키를 채웁니다
cp .env.local.example .env.local
#  (Windows PowerShell) Copy-Item .env.local.example .env.local

npm run dev -- -p 3456   # → http://localhost:3456
```

> ⚠️ **포트는 3456** — 카카오맵 도메인과 구글·카카오 OAuth 리디렉션 URI가 `localhost:3456`으로 등록돼 있어, 기본 3000으로 띄우면 로컬에서 지도·로그인이 동작하지 않는다.

`.env.local`에 채울 값 (발급 경로·함정은 [`.env.local.example`](.env.local.example)에 상세히):

```
TOUR_API_KEY=                 # 필수 — 공공데이터포털 일반 인증키(Decoding). 관광 데이터 전부 + 집중률·방문자수 배치 공용
WEATHER_API_KEY=              # ☔ 기상청 초단기실황 — 없으면 ☔ 조건만 조용히 건너뜀
NEXT_PUBLIC_KAKAO_MAP_KEY=    # 🗺️💬 카카오 JavaScript 키 (지도 + 카톡 공유)
AUTH_SECRET=                  # 🔐 Auth.js 세션 서명 (`npx auth secret`)
DATABASE_URL=                 # 🔐 Neon Postgres 연결 문자열
AUTH_GOOGLE_ID= / AUTH_GOOGLE_SECRET=
AUTH_KAKAO_ID= / AUTH_KAKAO_SECRET=
AUTH_REDIRECT_PROXY_URL=      # 🔁 Vercel Preview 배포 로그인 400 방지 (로컬은 비움)
CRON_SECRET=                  # 🍃 혼잡도 배치 인증 — Vercel env 등록 필수(미등록이면 cron이 401로 조용히 죽는다)
```

> 서비스키는 [공공데이터포털](https://www.data.go.kr)에서 활용신청(무료)으로 발급한다 — 관광 데이터(자동승인) · 기상청 단기예보 · 관광지 집중률 예측 · 지역별 방문자수. 무장애 여행정보만 별도 서비스로 활용신청이 하나 더 필요하다.

## 💰 수익 모델 (장기 구상)

사용자의 뽑기·반응·방문 행동 데이터를 **익명 집계 통계·트렌드 리포트**로 가공해 관광 업계(지자체·여행사 등)에 판매하는 모델. 개인 단위 데이터 판매가 아닌 통계 상품화 — 상세는 [plan.md](plan.md) §12.

1단계(익명 이벤트 수집)는 이미 가동 중이다: 계정과 이을 수 있는 외래키를 **아예 두지 않은** 이벤트 테이블에 뽑기·반응만 쌓고, 그 집계를 [`/impact`](https://travelanywhere-kr.vercel.app/impact) ③패널로 공개한다. 수집 범위 고지는 [`/privacy`](https://travelanywhere-kr.vercel.app/privacy).
